Getting a handle to a console stream:

    HANDLE WINAPI GetStdHandle(
            _In_ DWORD nStdHandle
        );

    HANDLE --> Handle to a stream (stdin, stdout, stderr)
    _In_ DWORD nStdHandle
        One of three values:
            STD_INPUT_HANDLE 
            STD_OUTPUT_HANDLE
            STD_ERROR_HANDLE
        They define what handle will this return

//--------------------------------------------------------------------------------------\\

Writting to an output console stream:

    BOOL or WINBOOL is just an typedefed int
    
    BOOL WINAPI WriteConsole(
    _In_             HANDLE  hConsoleOutput,
    _In_       const VOID    *lpBuffer,
    _In_             DWORD   nNumberOfCharsToWrite,
    _Out_opt_        LPDWORD lpNumberOfCharsWritten,
    _Reserved_       LPVOID  lpReserved
    );

    HANDLE hConsoleOutput--> Handle to a console output stream
    VOID *lpBuffer --> Pointer to an array of characters
    DWORD nNumberOfCharsToWrite --> DWORD is just a typedefed unsigned long (32 bytes on windows)
    LPDWORD lpNumberOfCharsWritten --> How much was actually written, used to check for errors
        LPDWORD --> Long Pointer to DWORD
    LPVOID lpReserved --> Something windows uses, dont use it
        LPVOID --> Long Pointer to VOID

    If it fails it will return 0
    If it succeds it will return 1
    for some reason...

Reading character input from an input stream
This one gives a segmentation fault every single time for no apparent reason the ReadFile works fine tho
    BOOL WINAPI ReadConsole(
        _In_     HANDLE  hConsoleInput,
        _Out_    LPVOID  lpBuffer,
        _In_     DWORD   nNumberOfCharsToRead,
        _Out_    LPDWORD lpNumberOfCharsRead,
        _In_opt_ LPVOID  pInputControl
    );

    HANDLE hConsoleInput --> Input stream
    LPVOID lpBuffer --> Array of characters
    LPVOID pInputControl --> The pointer to some CONSOLE_READCONSOLE_CONTROL struct, can be null thankfully

    BOOL ReadFile(
        [in]                HANDLE       hFile,
        [out]               LPVOID       lpBuffer,
        [in]                DWORD        nNumberOfBytesToRead,
        [out, optional]     LPDWORD      lpNumberOfBytesRead,
        [in, out, optional] LPOVERLAPPED lpOverlapped
    );

    HANDLE hFile --> Handle to a file stream
    LPVOID lpBuffer --> Ptr to a buffer (array of chars)
    DWORD nNumberOfBytesToRead --> How much it should be allowed to read (usually the size of buffer)
    LPDWORD lpNumberOfBytesRead --> How much it actually read, error checking, can be NULL
    LPOVERLAPPED lpOverlapped --> some struct, can be NULL
